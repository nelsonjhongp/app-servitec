# App-Servitec  
**Plataforma para la conexión de clientes y profesionales de servicios de trabajo en el hogar**  

## Descripción  
App-Servitec es una solución digital que optimiza la contratación de servicios en el hogar al conectar clientes con profesionales calificados. La aplicación centraliza las necesidades de ambos usuarios, ofreciendo una experiencia eficiente y personalizada. Se desarrollo este proyecto academico para el curso de integracion de sistemas y software.

### Características principales  
- **Gestión de usuarios**:  
  - Registro de clientes y trabajadores.  
  - Sistema de inicio de sesión con permisos según tipo de usuario (administrador, cliente, trabajador).  
- **Roles y funcionalidades**:  
  - **Administrador**:  
    - Visualización de usuarios registrados.  
    - Operaciones CRUD sobre usuarios y trabajadores.  
  - **Cliente**:  
    - Exploración de trabajadores disponibles y sus servicios.  
    - Calificación de profesionales tras completar el servicio.  
- **Interfaz gráfica**:  
  - Diseñada con **Java Swing**, ofreciendo una experiencia amigable y funcional.  
- **Base de datos centralizada**:  
  - Almacenamiento y gestión de datos a través de **MySQL** con conexión local mediante **XAMPP**.  

## Objetivo  
Crear una plataforma eficiente y confiable que facilite la conexión entre clientes que requieren servicios domésticos y profesionales calificados, asegurando transacciones seguras y satisfactorias.  

## Tecnologías utilizadas  
- **Lenguaje de programación**: Java 17  
- **Interfaz gráfica**: Java Swing  
- **Base de datos**: MySQL (gestión con XAMPP)  

## Habilidades aplicadas  
- Programación Orientada a Objetos (POO):  
  - Herencia  
  - Polimorfismo  
- Gestión de bases de datos centralizadas  

## Instalación y uso  
1. **Requisitos previos**:  
   - Java 8 o superior instalado.  
   - XAMPP configurado y ejecutándose.  
   - Base de datos MySQL con las tablas necesarias.  
2. **Configuración**:  
   - Clona este repositorio en tu máquina local.  
   - Configura las credenciales de la base de datos en el archivo de configuración de la aplicación.  
3. **Ejecución**:  
   - Compila y ejecuta el proyecto desde tu IDE preferido (Eclipse, IntelliJ, NetBeans).
